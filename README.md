# Security System Builder

## Tech Stack

- React
- Tailwind CSS
- Context API
- useReducer
- LocalStorage

## Install

```bash
npm install
```

## Run

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Features

- Multi-step Accordion
- Dynamic Product Cards
- Variant Selection
- Quantity Synchronization
- Live Review Panel
- LocalStorage Persistence
- Responsive Design
